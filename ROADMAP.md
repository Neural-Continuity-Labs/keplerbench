# Roadmap

## Included in 0.1.0

- public observation schema;
- deterministic synthetic central-force generator;
- observer-centred direction outputs;
- angular prediction metrics;
- level-1 harmonic baseline;
- evaluation contracts for all three capabilities; and
- automated tests and continuous integration.

## Required for the first benchmark release

- multi-world public development suite;
- evaluator-private held-out world suite;
- global-law adaptation harness;
- local-state rollout interface and validator;
- reference predictive, global-law, and local-law baselines;
- versioned dataset cards and checksums; and
- historical Mars and multi-planet releases after provenance review.

## Later extensions

- broader unfamiliar central-force families;
- observation selection and active experimentation;
- a curated pre-discovery corpus; and
- additional domains in which useful state variables are not supplied.
